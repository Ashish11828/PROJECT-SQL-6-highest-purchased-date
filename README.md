# SQL: Highest-Purchase Date

## Exercise

SQLite practice query that groups purchases by date and returns the day with the most purchases.

## Files

The query is stored in `SQL`. Open it as a text file and run it in a SQL environment containing the exercise tables. The query uses SQLite-style `STRFTIME`, groups purchase rows by date, and returns one row ordered by purchase count. Ties are not given a secondary ordering.

## Requirements

Load the matching `purchases` table before execution. This repository does not include a standalone database or seed data; query results depend on the exercise dataset.
